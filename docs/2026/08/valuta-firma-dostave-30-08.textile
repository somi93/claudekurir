h1. Валута фирме за доставу (30.8.2026)

h2. Контекст

Ресторани већ имају поље за валуту, унутар @settings@ JSON поља (нпр. @{"currency":"KM", ...}@). Фирма за доставу *нема* тренутно то поље постављено, иако @settings@ колона *постоји* и *већ прихвата* произвољан JSON преко постojeћег endpoint-a.

---

h2. Endpoint (постojи, само треба слати currency)

<pre>
PUT /api/companies-delivery/{id}
Body: { ..., "settings": { ..., "currency": "KM" } }
</pre>

Исти endpoint (@updateCompaniesDelivery@) који се *већ* користи за остала подешавања фирме (смjene, итд.) — само треба *додати* @currency@ кључ у постojeћи @settings@ објекат, исто као што се то ради за ресторан.

---

h2. Пословно правило (ВАЖНО — front треба да истакне корисницима)

*Фирма за доставу и сви ресторани са којима сарађуje требало би да имају усклађену (исту) валуту.*

Ово *није* тренутно технички приморано на backend страни (нема аутоматске блокаде/провере) — то је *пословно* правило које corisnici treba да поштуjу. Молимо да frontend:

* Прикаже јасну напомену/упозорење ако dispečer покуша да укључи сарадњу са рестораном чија валута *није иста* као валута фирме (упоредити @restaurant.settings.currency@ и @delivery_company.settings.currency@ на клиjентскоj страни, пре слања захтjeva)
* Омогући *унос* валуте за фирму у подешавањима (исти UI образац као ресторан)

*Напомена:* Ако backend валидациja/упозорење на серверскоj страни буде касниjе потребна (нпр. ако се покаже да corisnici игноришу упозорење), јавите — можемо додати проверу приликом укључивања сарадње (@toggle@ endpoint).
