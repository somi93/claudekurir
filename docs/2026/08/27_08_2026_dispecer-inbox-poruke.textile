h1. Диспечер: слање порука куририма (inbox систем)

Постојећи endpoint-и, данас само додата заштита (провjera да dispečer smije samo кuririma своје фирме).

*Важна напомена о обиму* — ово је *inbox* систем (курир мора да отвори апликацију и повуче поруке), *не* push нотификација у реалном времену. Ако треба и push, то је posebna, buduća integracija (види напомену на крају).

---

h2. 1. Слање поруке куриру

<pre>
POST /api/couriers/{courierId}/inbox
Authorization: Bearer &lt;token dispečera&gt;
Body:
{
    "sender": "dispatcher",
    "title": "Наслов поруке",
    "body": "Текст поруке..."
}
</pre>

*Одговор (успех):*
<pre><code class="json">
{
    "success": true,
    "data": {
        "id": 42,
        "courier_id": 30189,
        "sender": "dispatcher",
        "title": "Наслов поруке",
        "body": "Текст поруке...",
        "sent_at": "2026-08-27T14:30:00.000000Z",
        "read": false
    }
}
</code></pre>

*Ауторизација (НОВО, 27.8.2026)* — dispečer мора *дијелити активну везу* (delivery_company_user, сва три flag-a) са тим кuririm, преко исте фирме. Ако покуша да пошаље поруку куриру *друге* фирме:

<pre><code class="json">
{
    "message": "Niste ovlasceni da saljete poruke ovom kuriru."
}
</code></pre>
HTTP статус *403*.

*Опционо поље @sent_at@* — ако се не пошаље, поставља се аутоматски на тренутно време.

---

h2. 2. Историја порука (за преглед шта је послато)

<pre>
GET /api/couriers/{courierId}/inbox
Authorization: Bearer &lt;token&gt;
</pre>

Враћа *све* поруке тог курира, најновије прво — корисно за диспечера да провjeри шта је раније послато.

---

h2. Шта НИЈЕ покривено данас — push нотификације у реалном времену

Ово *inbox* решење захтева да курир *отвори* апликацију и *повуче* поруке (@GET .../inbox@) — нема аутоматског "звона" на телефону кад стигне порука.

*Постоји* @PushTokenController@ (регистрација device token-a за push), али *нисмо потврдили* да ли је *повезан* са овим inbox системом — треба посебна провjera/интеграција ако желите праву push нотификацију (нпр. кад стигне нова наруџба, аутоматски послати и inbox поруку и push).

Ово остаје *отворена* ставка за следећу сесију.
